# PoB2 control restyle

Repaints Path of Building 2's hand-drawn controls — softer borders, real
surface fills, calmer hover and press states, rounded corners. Pure
presentation: no layout, no sizes, no calc code touched.

Fork of PathOfBuildingCommunity/PathOfBuilding-PoE2 (MIT). Upstream is the
`upstream` remote; this work lives on the `ui-restyle` branch.

## Run it

The repo ships its own runtime, and running from the clone auto-enables Dev
Mode. Nothing to build.

```bash
cd runtime && "./Path{space}of{space}Building-PoE2.exe"
```

The `{space}` is literally part of the filename upstream — not a typo.

Edit any `.lua` under `src/`, press **F5** in the app, and it reloads in
place. That is the whole iteration loop.

## What changed

| File | What it drives |
|---|---|
| `src/Modules/Common.lua` | `uiStyle` table, `SetUIColor()`, `DrawRoundRect()` |
| `src/Assets/roundrect.png` | 64×64 corner texture (new, 419 bytes) |
| `src/Classes/ButtonControl.lua` | Every button |
| `src/Classes/CheckBoxControl.lua` | Every checkbox |
| `src/Classes/DropDownControl.lua` | Every dropdown, closed and open |
| `src/Classes/EditControl.lua` | Every text field |
| `src/Classes/ScrollBarControl.lua` | Every scrollbar |
| `src/Classes/SliderControl.lua` | Every slider |

59 color call sites and 17 geometry call sites, all reading from one table.

### Colors

Each control draws a 1px border rect, then a fill rect inset by 1px. That
structure is untouched; only the colors moved.

| Role | Was | Now | Why |
|---|---|---|---|
| Border, resting | `0.50` | `0.28` | Hairlines at half-white on near-black read as harsh |
| Border, hover | `1.00` | `0.46` | Pure white hover was the single most dated cue |
| Border, active | `0.75` | `0.60` | Checked boxes, dragged knobs |
| Border, disabled | `0.33` | `0.16` | Disabled was brighter than it should be |
| Fill, resting | `0.00` | `0.09` | Pure black gave controls no surface at all |
| Fill, hover | `0.33` | `0.15` | Lift, not a flash |
| Fill, pressed | `0.50` | `0.05` | Press was *lighter* than hover; now it sinks |
| Field, resting | `0.00` | `0.07` | Text fields read sunken vs. raised buttons |
| Field, focused | `0.10`/`0.15` | `0.11` | Collapsed two near-identical branches |

### Corners

`DrawRoundRect(x, y, w, h, radius)` is a drop-in replacement for
`DrawImage(nil, x, y, w, h)`. It draws four corner quads sampled from the
quadrants of a white disc texture, plus three solid rects for the middle —
seven draw calls where there was one. The quads are tinted by whatever
`SetDrawColor` is live, exactly like the square version, so nothing about
the color logic changes.

The texture is a 64×64 RGBA disc with 4×4 supersampled alpha, generated by
`restyle-tooling/apply_corners.py` rather than hand-drawn. Downscaling 32px of source radius
to a 4px corner is what gives the anti-aliasing.

Radius clamps to `min(radius, width/2, height/2)`, and falls back to a plain
square rect if the radius doesn't fit or the texture fails to load — so
nothing can draw a hole.

Scrollbars get the rounded treatment on the **knob only**. The arrow buttons
and groove are 16px chrome that reads better square, and a rounded knob in a
square groove is the shape most current scrollbars use.

## Tuning

All of it is at the bottom of `src/Modules/Common.lua`:

```lua
uiStyle = {
	radius         = 4,
	border         = { 0.28, 0.28, 0.31 },
	borderHover    = { 0.46, 0.46, 0.51 },
	...
}
```

Colors are linear RGB 0..1. The slight blue bias (third channel highest)
keeps the greys from looking muddy against PoE's warm item text. `radius` is
in pixels; set it to `0` to get the square look back without reverting
anything. Change a number, hit F5, look.

## A bug this pass fixed

The first pass put `uiStyle` and `SetUIColor` in `src/Data/Global.lua`,
alongside `colorCodes`. That was wrong: `Data/Global.lua` is only reachable
through `Modules/Data.lua`, which only `Modules/Main.lua` loads — but
`src/Export/Main.lua` (the GGPK data exporter) instantiates `ButtonControl`,
`EditControl` and `DropDownControl` too, without ever loading it. Every
control draw on that path would have hit a nil global.

Both entry points load `Modules/Common.lua`, so that is where the style
table, `SetUIColor` and `DrawRoundRect` now live. `Data/Global.lua` is back
to its upstream contents.

## Re-applying after a rebase

Both scripts match exact upstream text and report failures rather than
corrupting a file, so re-run them after pulling:

```bash
python -I restyle-tooling/apply_restyle.py && python -I restyle-tooling/apply_corners.py
```

Anything that could not be matched is printed by name; patch those by hand.

## Not done

- **Font.** Dead end for now — `runtime/SimpleGraphic/Fonts/` holds
  pre-rendered bitmap atlases (`.tga` + `.tgf` metrics) at 16 sizes per face.
  Swapping the typeface means regenerating all of them, which needs a
  generator for the `.tgf` format first.
- **Concentric corners.** The inner fill uses the same radius as the outer
  border rather than `radius - 1`, so the 1px border is very slightly thin
  at the corners. Invisible at radius 4; worth fixing if you push the radius
  higher.
- **Padding and hit targets.** Control sizes come from each tab's call site,
  so making things taller means touching every screen.
